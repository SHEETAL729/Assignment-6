Ques:-1  Create a class Employee with attributes emp_name, emp_id, and salary. Create 3 objects and display their details. 
Ans:
class Employee:
    def __init__(self, emp_name, emp_id, salary):
        self.emp_name = emp_name
        self.emp_id = emp_id
        self.salary = salary

    def display_details(self):
        print("Employee Name:", self.emp_name)
        print("Employee ID:", self.emp_id)
        print("Salary:", self.salary)
        print()


# Creating objects
emp1 = Employee("Sheetal", 101, 50000)
emp2 = Employee("Vikash", 102, 60000)
emp3 = Employee("Anil", 103, 55000)

# Displaying details
emp1.display_details()
emp2.display_details()
emp3.display_details()

Ques:-2 Create a class Calculator with methods for addition, subtraction, multiplication, and division. 
Ans:
class Calculator:
    def add(self, a, b):
        return a + b

    def subtract(self, a, b):
        return a - b

    def multiply(self, a, b):
        return a * b

    def divide(self, a, b):
        if b != 0:
            return a / b
        return "Division by zero is not allowed"


# Creating object
calc = Calculator()

# Using methods
print("Addition:", calc.add(10, 5))
print("Subtraction:", calc.subtract(10, 5))
print("Multiplication:", calc.multiply(10, 5))
print("Division:", calc.divide(10, 5))

Ques:-4 Create a class Vehicle with method display(). Inherit it into class Car and call parent method. 
Ans:
class Vehicle:
    def display(self):
        print("This is a Vehicle")


class Car(Vehicle):
    def show(self):
        # Calling parent class method
        super().display()
        print("This is a Car")


# Creating object of Car
c = Car()

# Calling methods
c.show()
